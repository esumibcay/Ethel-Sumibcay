# Briefs

Written **before** modeling: the problem in your own words, and a hypothesis you can be wrong about, committed before you model anything. A brief written after the analysis is a summary of the answer — worth nothing to you and obvious to anyone reading in order.

Name files by engagement, not by date/week (e.g. `perfect-competition-brief.md`), unless the guide's dated-document convention applies (`YYYY-MM-DD-slug.md`).
